راهنمای سریع تهران کلاب

1) Node.js 20+ نصب شود.
2) داخل پوشه بات: npm install
3) .env را بسازید و توکن بات، Client ID و Guild ID را بگذارید.
4) در Developer Portal، Message Content و Server Members Intent را روشن کنید.
5) npm run register
6) npm start
7) داخل سرور /setup را بزنید و تنظیمات را انجام دهید.

دستورهای مدیریتی:
setup / giveaway / drop / ticket / staff / rankup / rankdown / clear / kick / ban / timeout / warn / exchange / level / leaderboard / invites
